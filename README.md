# typemaps

Dos juegos estáticos, sin dependencias ni compilación:

- `tecleo/`: test de mecanografía con citas.
- `mapeo/`: escribe los países y colorea el mapa (Europa, mundo y Europa en 1914, 1920 y 1938).

`index.html` es el índice que enlaza a los dos.

Fronteras actuales: Natural Earth. Fronteras históricas: [historical-basemaps](https://github.com/aourednik/historical-basemaps) de André Ourednik (GPL-3.0).
